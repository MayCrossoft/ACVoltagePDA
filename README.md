# ACVoltage PDA

Самодельный КПК (PDA) на **ESP32-WROOM-32** + **ILI9341 2.8"** TFT-дисплей с тачскрином **XPT2046**. Интерфейс в стиле Windows 95 (с альтернативной темой Hotline Miami) — рабочий стол, панель задач, стартовое меню, набор игр, утилит и офисных приложений, всё на голом Arduino-коде.

---

## Возможности

### Рабочий стол и система
- Две темы оформления — **Windows 95** (классика) и **Hotline Miami** (тёмная, неоновая), переключаются в Настройках, применяются сразу по всему интерфейсу
- Стартовое меню: Neon Arcade / Calculator / Utilities / Settings / Power Off
- Меню выключения: выключить экран (сон по касанию для пробуждения), **гибернация** (`esp_deep_sleep_start()`, пробуждение только физическим сбросом — честно, без ложных обещаний), перезагрузка, отмена
- Загрузочная заставка (synthwave-стиль) при старте
- Заставка после простоя (настраиваемый таймаут): **Sunset Highway** с машиной, едущей на зрителя (Hotline Miami) или **Starfield** — разлетающиеся частицы (Windows 95); возвращает именно туда, где был открыт экран до простоя
- Трей на рабочем столе: индикатор силы сигнала Wi-Fi, время + день недели + дата (по NTP), иконка погоды + температура
- Звуковая обратная связь через пассивный пищалку (клик, победа/поражение, слияние в 2048, очистка линии в Тетрисе и т.д.), уважает громкость из Настроек
- **Аварийная перекалибровка тача**: держишь 3.3V на GPIO13 (перемычкой) 15 секунд на рабочем столе → подсказка → 10 тапов в любом месте экрана → перекалибровка. Работает даже если тач откалиброван настолько плохо, что точный тап по кнопке недоступен

### Neon Arcade
Arkanoid · Tetris · Tic-Tac-Toe · Pong (против ИИ) · 2048 (управление свайпами) · Space Invaders — у каждой игры свой рекорд в NVS, переживает перезагрузку.

### Calculator
Режимы через кнопку **Mode**: **Standard** (полноценные выражения с приоритетом операций, не только `x+y`), **BASE-N** (конвертер DEC/HEX/OCT/BIN), **Scientific** (sin/cos/tg/ctg угла + решатель прямоугольного треугольника — по двум сторонам ищет угол, по углу и стороне — другую сторону).

### Utilities
- **System Info** — версия прошивки, модель чипа, ядра, частота CPU, реальный размер и частота флеша, аптайм, свободная RAM
- **GPIO Test** — листаешь между несколькими свободными пинами, переключаешь вход/выход, Вкл/Выкл/Мигать или живое чтение HIGH/LOW
- **Stopwatch** — секундомер с сотыми долями секунды
- **QR Generator** — настоящий QR-код (Version 1, ECC уровень L, числовой режим), GF(256) и Рид-Соломон считаются алгоритмически в рантайме
- **Explorer** — файловый менеджер: разделы Flash (SPIFFS) и SD, список файлов с размером, удаление, создание новых заметок прямо отсюда
- **WiFi Scan** — список сетей поблизости с уровнем сигнала и типом шифрования
- **Touch Draw Test** — рисовалка для проверки качества калибровки, с сохранением/загрузкой зарисовок (хранятся как список отрезков, не растр)
- **Notepad** — список заметок + редактор с экранной QWERTY-клавиатурой, файлы в SPIFFS
- **Alarm Clock** — будильник по NTP-времени, полноэкранный сигнал с пищалкой до тапа

### Wi-Fi
- Список из нескольких сохранённых сетей (не одна), автоподключение при старте к первой найденной знакомой сети
- Фоновое автопереподключение, если связь пропала — не блокирует интерфейс
- Настройка через **сканирование эфира** — выбираешь SSID тапом из списка, вводишь только пароль; ручной ввод SSID остаётся как резерв для скрытых сетей
- NTP-синхронизация времени и даты (часовой пояс зашит как MSK/UTC+3 — поправь `WIFI_GMT_OFFSET_SEC` в `wifi_manager.h` под себя)
- Погода через Open-Meteo (без API-ключа), координаты зашиты фиксированно — поправь `WEATHER_LAT`/`WEATHER_LON` в `weather.h`

## Схема подключения

| Сигнал | ESP32 GPIO | Назначение |
|---|---|---|
| TFT_CS | 15 | Дисплей |
| TFT_DC | 2 | Дисплей |
| TFT_RST | 4 | Дисплей |
| TFT_MOSI | 23 | Дисплей + тач (общая линия) |
| TFT_SCLK | 18 | Дисплей + тач (общая линия) |
| TFT_MISO | 19 | Дисплей + тач (общая линия) |
| TOUCH_CS | 21 | Тач |
| T_CLK / T_DIN / T_DO | 18 / 23 / 19 | Тач (параллельно линиям дисплея — шина SPI это позволяет) |
| TOUCH_IRQ | 22 | не используется — опрос поллингом, можно не подключать |
| SD_CS | 5 | SD-карта (опционально) |
| Подсветка (BL) | 32 | ШИМ-регулировка яркости |
| Тестовый LED / аварийная перекалибровка | 13 | GPIO-тестер, аварийная перекалибровка тача |
| Пищалка (buzzer) | 27 | Звуковая обратная связь |

Питание дисплея и тача — 3.3V (сверь по маркировке своего конкретного модуля — часть версий ILI9341 со встроенным стабилизатором терпит 5V на VCC).

### Питание от батареи (опционально)
Собрана и проверена связка: **18650 Li-ion (3.7V) → TP4056 с защитой (USB Type-C) → повышающий модуль (boost) до 3.3V → ESP32**. Держатель — с закрытыми контактами (не голые пружинки), либо батарея с уже распаянным проводом+JST-разъёмом, если не хочется паять на самой ячейке.

## Настройка окружения (Arduino IDE)

1. Установи пакет плат **ESP32 (Espressif Systems)** через Boards Manager.
2. Установи библиотеку **TFT_eSPI** (автор Bodmer) через Library Manager.
3. Скопируй `User_Setup.h` из этого репозитория в папку библиотеки:
   `Documents/Arduino/libraries/TFT_eSPI/User_Setup.h` (с заменой существующего).
4. Плата: **ESP32 Dev Module**.
5. **Flash Size** — выставь честно, под реальный физический чип.
6. **Partition Scheme** — рекомендуется **Huge APP (3MB No OTA/1MB SPIFFS)** для чипов 4MB: даёт наибольший доступный раздел под код, поскольку OTA-обновления не используются.
7. Положи все файлы репозитория в одну папку **с именем, точно совпадающим с именем `.ino`-файла** (это жёсткое требование Arduino — иначе будет "undefined reference to setup()/loop()").

### Диагностика реального размера флеша
Если не уверен в физическом объёме чипа или в свободном месте под текущую схему — можно временно добавить в `setup()` вывод в Serial:
`ESP.getFlashChipSize()`, `ESP.getSketchSize()`, `ESP.getFreeSketchSpace()`, `ESP.getFreeHeap()` — то же самое, что уже показывает встроенный экран **System Info**, только доступно ещё до заливки полной прошивки.

### Первый запуск
При первом старте (или после сброса NVS) запросит калибровку тача — коснись углов экрана по подсказке. Данные калибровки сохраняются в NVS через `Preferences`, повторно калибровать не придётся, пока не сотрёшь флеш или не запросишь перекалибровку вручную (значок-мишень в углу экрана Настроек, либо аварийный способ через GPIO13 — см. выше).

## Известные ограничения

- **QR-генератор** ограничен Version 1 (21×21 модуль), ECC уровнем L и числовым режимом (до ~41 цифры) — сознательное упрощение ради надёжности реализации без внешних библиотек. Маска всегда 0 (валидно по спецификации, просто не оптимизирована под сложные условия сканирования).
- **Гибернация** не имеет источника пробуждения по тачу — GPIO22 (тач-IRQ) не RTC-совместимый пин. Разбудить можно только физической кнопкой EN/RESET на плате.
- **Часовой пояс и координаты погоды** зашиты как константы (MSK, Москва) — не настраиваются через интерфейс, только правкой кода.
- Реального звука (кроме пищалки на `tone()`/`noTone()`) нет — для полноценного аудио нужен I2S DAC, в проекте не реализован.
- Тач опрашивается поллингом, не прерыванием (`TOUCH_IRQ` не задействован) — небольшая, но не нулевая задержка отклика.

## Структура проекта

Однофайловых модулей нет намеренно — каждый экран/приложение/утилита в своём `.h`, чтобы Arduino IDE показывала их отдельными вкладками. Главный файл `ACVoltagePDA.ino` — стейт-машина экранов, ничего кроме навигации и `setup()`/`loop()` в нём нет.

Ключевые инфраструктурные файлы:
- `theme.h` — переключаемая палитра цветов (Windows 95 / Hotline Miami)
- `ui.h` — переиспользуемые виджеты (кнопки, рамки, тайтлбары)
- `touch.h` — калибровка и чтение тача
- `wifi_manager.h` — список сетей, автоподключение, NTP
- `highscore.h` — обёртка над NVS для рекордов/счётчиков
- `app_keyboard.h` — экранная QWERTY-клавиатура, используется Notepad и Wi-Fi Setup
